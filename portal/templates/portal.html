功能介绍 — 各模块使用说明

📊 社保批量统计智能核算系统

  1. 进入模块后，先上传社保权益记录单（图片或 PDF，支持批量与文件夹导入）；
  2. 系统自动 OCR 识别人员姓名、证件号与四险（养老/医疗/工伤/失业）缴费起止时间；
  3. 可上传人员花名册进行姓名匹配，系统校验缴费单位一致性；
  4. 按统计时间段自动核算四险重叠月数，并结合劳动合同区间计算有效参保期；
  5. 支持"退税 / 抵税"两种税种模式切换、手动补录、时间段修改；
  6. 一键生成总台账 / 年度台账 Excel，并可对识别异常的图片进行文件整理归档。

📋 劳动合同图片整理系统

  1. 先上传人员花名册（Excel），系统解析人员顺序；
  2. 再上传劳动合同图片或 PDF（支持文件夹批量导入）；
  3. 系统按花名册顺序自动重命名合同文件，同一人多文件时自动编号；
  4. 转换前可预览重命名计划，确认后执行，支持一键回滚。

📄 批量PDF转WORD系统（v2.0.0 可逆转换）

  1. PDF 转 Word：批量上传 PDF，转换为可编辑的 Word（.docx），保留文本、图片、表格与排版；
  2. 其他格式转 PDF（可逆转换）：选择"其他格式转 PDF"方向后，可将图片 / Word / Excel / TXT 批量转为 PDF，支持选择整个文件夹递归解析；
  3. 合并模式：按上传顺序将全部文件合并为单个 PDF；
  4. 独立模式：每个文件生成独立 PDF，命名与源文件一致（重名自动加序号），一一对应可溯源；
  5. 不支持的格式、空文件或转换失败的文件会给出明确提示，单个文件失败不影响整体任务。

🏥 医保参保证明批量下载系统

  1. 上传员工花名册；
  2. 系统自动打开陕西医保网厅并完成登录；
  3. 逐人查询并批量下载职工参保证明 PDF；
  4. 文件以姓名命名，自动归档到日期文件夹。

💡 使用提示

  • 标题栏右侧"账号管理"菜单中可进行账号、邀请码与密码管理；
  • "关于系统"菜单中可查看本功能介绍，或通过"版本更新"检查并升级新版本；
  • 各模块页面右上角均提供"返回首页"入口。

📊 社保批量统计智能核算系统

面向重点群体就业税收优惠申报，自动完成参保证明的识别、统计与核算。

  1. 进入模块后选择参保所在省份与税种类型（退税 / 抵税）；
  2. 上传员工花名册（Excel）——花名册为统计唯一基准，按身份证号唯一匹配；
  3. 上传社保权益记录单图片或 PDF（支持文件夹批量导入），系统自动 OCR 识别；
  4. 自动统计四险（养老 / 失业 / 医疗 / 工伤）重叠月数，结合劳动合同区间计算有效参保期，中断信息自动剔除；
  5. 一键生成退税核算 Excel 台账（总台账 / 年度台账），并自动整理归档证明文件；花名册外与识别异常的图片保留原名、单独标注待处理。

📋 劳动合同图片整理系统

按花名册顺序批量整理合同影像，支持 PDF 转图片、同人编号。

  1. 上传人员花名册（Excel），系统解析人员顺序；
  2. 上传劳动合同图片或 PDF（上传卡片支持展开 / 折叠，便于大批量操作）；
  3. 系统按花名册顺序自动重命名，同一人多文件自动追加序号编号；
  4. 下载整理后的文件包，重名与未匹配文件单独标注待处理。

📄 批量 PDF 转 WORD 系统

双向批量转换：PDF 转 Word（保留排版），或图片 / Word / Excel / TXT 转 PDF。

  1. 选择转换方向后上传文件或整个文件夹（自动递归扫描）；
  2. 转 PDF 时可选择合并模式（按顺序合成单个 PDF）或独立模式（逐文件一一对应）；
  3. 转换自动生成校验报告，结果一键打包下载；单个文件失败不影响整体任务。

🏥 医保参保证明批量下载系统

面向陕西医保网厅，逐人查询并批量下载职工参保证明。

  1. 上传员工花名册；
  2. 系统自动打开陕西医保网厅，完成登录；
  3. 逐人查询并自动下载参保证明 PDF，以姓名命名、归档到日期文件夹。

🔌 MCP 智能服务端

允许 AI 助手通过 MCP 协议直接调用平台能力（对话即操作），入口见"关于系统 → MCP模块"。

  • 提供 7 个工具：省份查询、社保核算、PDF转Word、转PDF、合同整理、任务状态、任务结果；
  • 强制两阶段确认：AI 首次调用任何工具（核算/整理/转换）一律先返回预览——社保为份数清点与花名册概览、合同为重命名计划、转换为文件清单与输出方式，均须呈现给用户、经用户确认后才执行；确认时可修正参数（省份、税种、统计年月、花名册、输出方式等）；
  • 隐私保护：结果只返回摘要与文件卡片，含身份证号的明细一律落盘为文件；独立 Token 鉴权，支持总开关。

💡 使用提示

  • 批量核算任务执行期间请保持平台开启，任务不支持中途取消与断点续跑；
  • AI 经 MCP 提交的核算/整理/转换任务一律先出预览，经您确认后才执行，不会未经确认直接跑；
  • "关于系统 → 版本更新"可在线检查并升级新版本，升级全程自动完成；
  • 各模块页面右上角均提供"返回首页"入口。
